# Plixlab

Turn your idea into a plix: a self-contained deck holding data, code and visualization. Python cells run in the browser or on cloud machines, and Claude builds the deck for you: slides, text, equations, diagrams, tables, molecules from the Protein Data Bank, and the Python cells that compute the charts.

## What this plugin does

It adds one thing: the Plixlab MCP connector, a remote server at `https://mcp.plixlab.com`. It contains no skills, commands, hooks, agents or local code.

On first use Claude asks you to sign in to your Plixlab account (OAuth). The connector then reads and changes only the presentations, data and settings of the account you connect. Nothing else is sent anywhere.
